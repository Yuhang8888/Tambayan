# Tambayan
Intranet til resturant Tambayan

Flask Inventory & Scheduling App
Dette er en webapplikation bygget med Flask, som håndterer lagerstyring af ingredienser, medarbejdervagtskemaer og menuhåndtering. Applikationen kommunikerer med en PostgreSQL database og benytter miljøvariabler til konfiguration.

Funktioner
Inventory Management: Visning af ingredienser med status baseret på lagerbeholdning og tærskelværdier.

Tilføj og træk lager: Mulighed for at tilføje og trække mængder fra lageret.

Fjern retter fra menu: Fratrækning af ingredienser baseret på antal af valgte retter.

Vagtskema: Opret og vis medarbejderes arbejdstider fordelt på dage og tidspunkter.

Flere statiske sider: medarbejderinfo, beskeder, og personlige oplysninger.
